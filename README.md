# قارئ المخططات — Floor Plan Engine

تطبيق Python/OpenCV لتحليل مخطط طابق من صورة أو PDF، واستخراج أسماء الغرف وأبعادها المطبوعة، وربطها بحدود هندسية ومساحات. يتضمن واجهة عربية RTL، واجهة API، وسطر أوامر.

> هذا إصدار عملي أولي: حدود الغرف ومقياس الرسم المستنتجان إرشاديان ويجب مراجعتهما بصريًا. لا تعتمد عليه وحده في رسومات تنفيذية أو تسعير نهائي.

## ما الذي يعمل؟

- رفع PNG وJPG/JPEG وBMP وTIFF أو PDF؛ عند PDF يحلل التطبيق **الصفحة الأولى** ويذكر ذلك.
- قراءة أسماء غرف وأبعاد إنجليزية شائعة، مع دعم اختياري للمفردات العربية عند تثبيت بيانات Tesseract العربية.
- تحويل `13'4" × 17'0"` إلى قدم مربع، ودعم أبعاد مترية مطبوعة.
- تقدير مقياس الصورة من الغرف ذات الأبعاد والمنطقة الهندسية، عند توفر ما يكفي من البيانات.
- حدود خضراء للمناطق المستخرجة من الجدران، وبرتقالية للحدود المستنتجة من الأبعاد ومُسنَدة إلى الجدران القريبة عند الإمكان.
- بطاقة لكل غرفة تعرض الاسم، الأبعاد المقروءة، المساحة، مستطيل الحدود، طريقة الحد، والثقة الإرشادية.
- صورة overlay قابلة للتنزيل وJSON منظّم لكل النتائج.
- معالجة صورة الرفع داخل الخادم من دون حفظ النسخة الأصلية؛ تُحفَظ صورة النتيجة فقط، وتُحذف النتائج الأقدم عند تجاوز 30 نتيجة.

## المتطلبات

- Python 3.10 أو أحدث (يوصى بـ 3.11+).
- Tesseract OCR مع بيانات اللغة الإنجليزية.
- Poppler لتحويل صفحات PDF إلى صور.

على Ubuntu/Debian:

```bash
sudo apt-get update
sudo apt-get install -y tesseract-ocr poppler-utils
```

للمخططات العربية ثبّت بيانات اللغة العربية واضبط متغير البيئة:

```bash
sudo apt-get install -y tesseract-ocr-ara
FLOORPLAN_OCR_LANG=eng+ara python run.py
```

على Windows ثبّت Tesseract وPoppler، واجعل `tesseract.exe` و`pdftoppm.exe` متاحين في `PATH`.

## التثبيت والتشغيل

من مجلد المشروع:

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\\Scripts\\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python run.py
```

افتح <http://127.0.0.1:8000>. لتغيير المنفذ/عنوان الاستماع:

```bash
HOST=0.0.0.0 PORT=8000 python run.py
```

في PowerShell استخدم `$env:HOST='127.0.0.1'; $env:PORT='8000'; python run.py`.

في الصفحة يمكنك رفع ملفك أو الضغط على **جرّب على المخطط التجريبي** لمشاهدة تحليل `test_floorplan.png` المرفق.

## تحليل من سطر الأوامر

```bash
python -m engine test_floorplan.png --out output/analysis
```

الناتج:

- `output/analysis/overlay.png` — صورة حدود الغرف.
- `output/analysis/rooms.json` — الأسماء والأبعاد والمساحات والحدود والتحذيرات.

ويمكن تشغيل العينة مباشرة بلا معاملات؛ أو تشغيل `python -m engine.pipeline` للتوافق مع نقطة الدخول القديمة.

## API

- `GET /health` — حالة التطبيق وتوفر OCR.
- `POST /api/analyze` — `multipart/form-data` بحقل ملف اسمه `file`.
- `POST /api/sample` — يحلل المخطط التجريبي المرفق.
- `GET /api/results/<result_id>/overlay.png` — يعيد overlay للنتيجة.

حد الرفع 20 MB وحد الصورة المفكوكة 25 ميغابكسل. مثال:

```bash
curl -F 'file=@test_floorplan.png' http://127.0.0.1:8000/api/analyze
```

## الاختبارات

```bash
pytest -q
```

الاختبارات الآلية موجودة داخل `tests/`. ملفات `test_*.py` القديمة في الجذر سكربتات استكشافية ترسم مخرجات؛ لا تُشغّل تلقائيًا من pytest بسبب `pytest.ini`.

## كيف تُقرأ النتائج؟

- **المساحة ذات المصدر `printed-dimensions`**: ناتجة من ضرب البعدين المقروءين من المخطط.
- **`pixel-scale-estimate`**: تحويل تقريبي من البكسلات إلى وحدة طول عبر مقياس مستنتج من عدة غرف؛ الثقة أقل.
- **`wall-region`**: مضلع منطقة مغلقة استخرجها محرك الجدران.
- **`dimension-box-wall-snapped`**: مستطيل مشتق من أبعاد الغرفة والمقياس، مع محاولة مطابقة أضلاعه مع بكسلات الجدران القريبة.
- **`dimension-box-estimate` و`wall-ray-estimate`**: تقديرات هندسية وليست قياسًا مؤكدًا.
- قيمة الثقة heuristic أولي وليست احتمالًا إحصائيًا مُعايرًا.

## حدود النسخة الحالية

- OCR الافتراضي هو `eng`. دعم المفردات العربية موجود لكنه يحتاج تثبيت `tesseract-ocr-ara` وتشغيل `FLOORPLAN_OCR_LANG=eng+ara`؛ وقد تختلف جودة التعرف باختلاف الخط والنسخة.
- التعرّف على مناطق مفتوحة، غرف متصلة بالأبواب، خطوط الأثاث، اختلاف سماكات الجدران، النص المائل، المخططات منخفضة الدقة، والأبعاد المشوشة قد ينتج دمجًا أو فصلًا خاطئًا.
- المنطقة المستخرجة من الجدران قد لا تطابق حدود غرفة واحدة، لذلك تُقارن هندسيًا بأبعاد النص ثم قد يُستخدم مستطيل تقديري.
- تحقق الجودة الآن مبني على مخطط اختبار واحد، وليس مجموعة مخططات متنوعة بعلامات أرضية مرجعية. يلزم جمع أمثلة مرخصة وتعليم حدودها يدويًا وإضافة مقاييس IoU/دقة OCR قبل الاعتماد التجاري.
