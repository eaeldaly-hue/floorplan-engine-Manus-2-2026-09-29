# قارئ المخططات — floorplan-engine

مشروع Python/OpenCV لتحليل مخطط طابق: يقرأ أسماء الغرف والأبعاد المطبوعة باستخدام Tesseract، يربطها بمناطق هندسية، ويُرجع حدودًا مرئية ومساحات مع توضيح مصدر كل نتيجة. يحتوي المستودع على واجهة عربية لرفع الصور وملفات PDF، وعلى pipeline هندسي مستقل لتجارب الجدران والغرف.

## تشغيل سريع

المتطلبات: Python 3.10+، Tesseract OCR، وPoppler لتحويل PDF.

```bash
# Ubuntu / Debian
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-eng poppler-utils

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

افتح `http://127.0.0.1:8000`. التشغيل محلي افتراضيًا؛ لتغيير المنفذ استخدم `PORT=8080 python run.py`. لا ترفع خادمًا على شبكة عامة قبل إضافة مصادقة وسياسة احتفاظ مناسبة لملفات المستخدمين.

لتمكين OCR العربي إذا كانت بيانات Tesseract العربية متاحة:

```bash
sudo apt-get install -y tesseract-ocr-ara
FLOORPLAN_OCR_LANG=ara+eng python run.py
```

يعمل المشروع افتراضيًا بلغة `eng` إذا كانت اللغة المطلوبة غير مثبتة. تُحدَّد اللغة قبل تشغيل العملية لأن إعدادها يُخزَّن مؤقتًا.

تُشغَّل قراءات Tesseract المستقلة لكل صفحة بالتوازي (حتى 8 عمليات افتراضيًا). لتغيير العدد استخدم `FLOORPLAN_OCR_WORKERS=4 python run.py`؛ القيمة `1` تُعيد التشغيل التسلسلي بالكامل. النتائج متطابقة في الحالتين (انظر `docs/OCR_PERFORMANCE.md`).

## واجهة وAPI

- `GET /` — واجهة رفع عربية RTL، مع تجربة على المخطط المضمن.
- `GET /health` — حالة التطبيق وتوفر Tesseract.
- `POST /api/analyze` — `multipart/form-data` بحقل `file`؛ يقبل PNG/JPG/BMP/TIFF وPDF.
- `POST /api/sample` — تحليل `test_floorplan.png`.
- `GET /api/results/<result_id>/overlay.png` — صورة المعاينة الناتجة.

الاستجابة تتضمن `rooms[]`: الاسم والنص المقروء، الثقة، الأبعاد، المساحة ومصدرها، مضلع الحدود وطريقة تقديره. الملفات الأصلية لا تُحفظ؛ تُحفظ معاينات النتائج مؤقتًا ويُحتفظ بأحدث 30 نتيجة. يقبل التطبيق ملفات حتى 20 MB وصورًا/صفحات PDF حتى 25 ميغابكسل بعد التحويل. في PDF متعدد الصفحات تُحلّل الصفحة الأولى فقط.

## ماذا تعني المساحة والحدود؟

- إذا قرأ النظام بعدين مطبوعين للغرفة، يعرض المساحة كحاصل ضرب البعدين؛ هذا **تقدير مستطيل من نص المخطط**، وليس مساحة مضلع مقاسة. قد يختلف عن المساحة الحقيقية للغرفة غير المنتظمة.
- الحدود الخضراء تتبع منطقة جدران مكتشفة. البرتقالية مستنتجة من الأبعاد ومُحاذاة إلى الجدران القريبة عندما أمكن. ليست كل الحواف مكتشفة مباشرة.
- نتيجة العينة الحالية: 17 اسم غرفة، و17 زوج أبعاد، و17 حدًا مرئيًا؛ منها 12 حدًا من مناطق الجدران و5 مستطيلات أبعاد مُحاذاة (غرف في منطقة مفتوحة واحدة بلا جدران فاصلة: المعيشة والمطبخ والممرات). استُنتج المقياس من 12 غرفة ذات منطقة مفردة. الفتحات: 17 بابًا و11 نافذة و3 فتحات غير مصنفة، مطابقة للتعليم اليدوي في `benchmark/fixtures/`. هذه أرقام لهذه الصورة وإصدار OCR الحالي، وليست ضمانًا لكل المخططات.
- لا تستخدم النتائج وحدها للتنفيذ أو الترخيص أو التسعير. راجع المخطط والقياسات بواسطة مختص.

## الـpipeline الهندسي

```bash
python -m engine.pipeline
```

يقرأ `test_floorplan.png` ويكتب نواتج الجدران والمساحات في `output/`. لتغيير المدخلات برمجيًا:

```python
from engine.pipeline import run
result = run(image_path="my_floorplan.png", output_dir="my_output")
```

يستخدم هذا المسار وتحليل الـAPI المحرك البنيوي نفسه (`engine/structure.py`): قناع جدران بالسماكة دون رسم جدران غير موجودة، فجوات الجدران كمرشحات فتحات، إغلاق الفجوات لتقسيم المساحات، وطوبولوجيا غرفة↔غرفة وغرفة↔خارج. في العينة: 16 مساحة مغلقة تغطي مراكز أسماء الغرف الـ17، و31 فتحة. التفاصيل والقياسات في `docs/OPENINGS_AND_STRUCTURE.md`.

## ملاحظات التنفيذ

- يُعالج OCR محليًا عبر Tesseract؛ لا توجد خدمة نموذج سحابي مطلوبة.
- كشف الأبواب والنوافذ حتمي (OpenCV/NumPy) بلا تعلم آلي: لكل فتحة أدلة (خطوط الزجاج، قوس الفتح، ورقة الباب، الانزلاق، العلاقة الطوبولوجية، العرض) وسبب مكتوب؛ وحين لا تكفي الأدلة تُعاد كفتحة غير مصنفة. الموقع على جدار خارجي وحده لا يجعلها نافذة.
- راجع `MIGRATION_NOTES.md` لتاريخ الانتقال والقيود المعروفة.
